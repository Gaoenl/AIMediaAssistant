# 平台矩阵与热点数据源调研

> 调研日期:2026-08-27
> 调研目的:为 AIMA 项目确定 MVP 分发平台范围与热点采集数据源
> 方法:以官方文档/官方开放平台页面为准,辅以公开社区资料交叉验证;标注"待确认"的条目需在实施前复核

## 一、平台发布能力矩阵

### 1. 微信公众号 — 第一档(需认证)

- 官方接口:草稿箱 `/cgi-bin/draft/add`(新建草稿)、发布 `/cgi-bin/freepublish/submit`(提交发布);发布为异步任务,完成后向开发者回调 URL 推送 `PUBLISHJOBFINISH` 事件
- 资质:发布接口面向已认证公众号;企业主体认证号可走完整发布链路,个人主体无法认证、只能进草稿
- 频率/限制:发布为异步,无硬性频率数字,但受微信风控
- 数据接口:有(用户分析、图文分析等)
- 结论:**第一档,建议作为第一个接入平台**
- 来源:
  - 微信开放社区-发布能力事件推送:[fuwu.weixin.qq.com/community/develop/doc/000228f26e88c82cdf022d2376b400](https://fuwu.weixin.qq.com/community/develop/doc/000228f26e88c82cdf022d2376b400)
  - 微信开放社区-发布任务异步说明:[fuwu.weixin.qq.com/community/develop/doc/0006869d8e40985e13b0cda7c66000](https://fuwu.weixin.qq.com/community/develop/doc/0006869d8e40985e13b0cda7c66000)
  - 草稿箱接口资料:[blog.csdn.net/m0_63174581/article/details/160119082](https://blog.csdn.net/m0_63174581/article/details/160119082)(社区资料,接口路径与官方一致)

### 2. 抖音开放平台 — 第一档(需企业资质)

- 官方接口:创建视频、创建图文(发布后平台审核)
- 资质:企业/个体户主体,企业身份认证 + 对公认证 + 应用审核
- 数据接口:有
- 结论:**第一档(视频/图文)**
- 来源:
  - 创建视频:[developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/video-create](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-video/video-create)
  - 创建图文:[partner.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-image-text/create-image-text](https://partner.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/create-image-text/create-image-text)
  - 入驻流程:[partner.open-douyin.com/docs/resource/zh-CN/developer/join/join-into-developer-platform](https://partner.open-douyin.com/docs/resource/zh-CN/developer/join/join-into-developer-platform)

### 3. 百家号 — 第一档(门槛较低)

- 官方接口:图文发布(openauth 开发者文档,"创建图文内容")
- 资质:百家号账号状态正常 + 开发者服务申请,门槛相对低
- 限制:内容审核;同文去重,相同文章禁止重复提交
- 数据接口:有
- 结论:**第一档(图文)**
- 来源:[baijiahao.baidu.com/builder/author/openauth/openauthProtection](https://baijiahao.baidu.com/builder/author/openauth/openauthProtection)

### 4. B站开放平台 — 第一档(视频)/待确认(专栏)

- 官方接口:视频投稿(上传预处理 + 稿件提交)
- 资质:境内企业法人营业执照(有效期 1 个月以上)+ 入驻承诺函加盖公章
- 结论:**第一档(视频);专栏/图文发布能力待确认**
- 来源:
  - 开放平台运营规范:[openhome.bilibili.com/agreement/management-protocol](https://openhome.bilibili.com/agreement/management-protocol)
  - 视频投递流程:[www.bilibili.com/read/cv16925213](https://www.bilibili.com/read/cv16925213/)

### 5. 微博开放平台 — 第二档(受限)

- 有发微博接口,但应用审核严格;发微博频率限制:单用户每应用 15 次/小时、50 次/天
- 平台对机器人调用识别严格
- 结论:**不建议第一档,按第二档半自动对待**
- 来源:[open.weibo.com 接口访问频次权限](https://open.weibo.com/darwin/wiki/%E6%8E%A5%E5%8F%A3%E8%AE%BF%E9%97%AE%E9%A2%91%E6%AC%A1%E6%9D%83%E9%99%90-)

### 6. 头条号 — 第二档

- 旧"头条开放平台"已停止注册,目前无可用的官方内容发布 API
- 结论:**第二档半自动**
- 来源:社区讨论(V2EX):[global.v2ex.co/t/948772](https://global.v2ex.co/t/948772)

### 7. 知乎 — 第二档

- 无面向普通第三方的内容发布 API
- 结论:**第二档半自动**
- 来源:待进一步官方确认(知乎开放平台当前以授权/内容展示能力为主)

### 8. 小红书 — 第二档/受限

- 笔记发布/笔记详情等接口仅对企业资质审核通过的合作方(品牌服务商、合规内容平台)开放,个人开发者无法申请
- 结论:**第二档半自动(普通账号);企业场景可申请评估**
- 来源:
  - 小红书开放平台对接资料:[www.php.cn/faq/2511984.html](https://www.php.cn/faq/2511984.html)
  - 笔记详情接口开放范围:[blog.csdn.net/ID_18007905473/article/details/156764865](https://blog.csdn.net/ID_18007905473/article/details/156764865)

### 9. 视频号 / 快手 — 待确认/第二档

- 视频号、快手目前未发现面向普通开发者的内容发布开放 API(快手开放平台以电商/小程序能力为主)
- 结论:**待确认,暂按第二档对待**

### MVP 平台建议

- 第一档接入顺序:公众号(认证号,第一个)→ 按内容形态选百家号(图文)或抖音(视频);B站放 M3 之后
- 第二档半自动:微博、知乎、小红书、头条
- 第三档:不做

MVP 结论:**3 个主源 + 1 个静态源**——知乎热榜、B站热门、36氪/虎嗅 RSS、节日日历;微博热搜作为实验源列入二期。

## 三、对方案文档的影响

1. 微信发布为异步,`publish_task` 状态机需增加 `WAIT_CALLBACK` 状态,并新增平台回调 Webhook(验签)
2. 第一档接入需要企业主体资质(公众号认证、抖音对公认证、B站执照),MVP 排期前需确认主体
3. 热点采集第一批全部为低风险源,无需爬虫对抗,采集链路简单稳定
